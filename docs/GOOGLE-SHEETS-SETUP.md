# 雲端同步設定：個人 Google 帳號 + Google 試算表

v6 起，班級經營動力站不再使用 Firebase。雲端同步改成「老師自己的 Google 帳號」授權，資料寫到「老師自己的」Google 試算表。**不設定也能使用**：資料會存在這台電腦的瀏覽器（IndexedDB）。

> ⚠️ 使用前請先確認學校的個人資料規定：試算表會存放學生座號、姓名、加扣分與作業紀錄。若學校要求使用學校核准的 Google Workspace 帳號，請用該帳號建立下列設定。

## 一、只需要做一次：建立 OAuth Client ID（約 10 分鐘）
1. 用你要存放資料的 Google 帳號登入 <https://console.cloud.google.com/>，建立一個新專案（例如「班級動力站」）。
2. 「API 和服務 → 程式庫」：搜尋 **Google Sheets API**，按「啟用」。
3. 「API 和服務 → OAuth 同意畫面」：
   - 使用者類型：個人帳號選「外部」；學校 Workspace 帳號可選「內部」。
   - 填寫應用程式名稱、支援電子郵件。
   - 範圍（Scopes）加入：`https://www.googleapis.com/auth/drive.file`（只能存取本 App 建立或你用本 App 開啟的檔案；看不到你雲端硬碟的其他檔案）。
   - 若是「外部」且在「測試」狀態：在「測試使用者」加入你自己的 Gmail。
4. 「API 和服務 → 憑證 → 建立憑證 → OAuth 用戶端 ID」：
   - 應用程式類型：**網頁應用程式**
   - 已授權的 JavaScript 來源：填你開啟 App 的網址的「來源」，例如
     - 正式網站：`https://yongliancai.github.io`
     - 在自己電腦測試：`http://localhost:8765`
   - 不需要填「重新導向 URI」。
5. 建立後複製 **用戶端 ID**（長得像 `1234567890-abc123.apps.googleusercontent.com`）。
   - **用戶端密鑰（client secret）完全不需要**，請不要貼到任何地方、也不要放進 GitHub。

## 二、第一台電腦
1. 開啟 App → 右上（總覽）或班級畫面的「☁️ 雲端狀態」按鈕。
2. 貼上 OAuth Client ID → 「🔐 連接 Google 帳號」→ 在 Google 視窗同意。
3. 按「＋ 建立新的試算表」。完成後可按「開啟 Google 試算表 ↗」查看。

## 三、其他電腦
1. 同樣貼上 Client ID → 連接 Google 帳號。
2. 在「試算表」貼上第一台電腦那份試算表的網址 → 「使用這份」。資料會自動合併。

## 四、平常使用
- 每次修改先存在本機，幾秒後自動同步；離線時照常使用，恢復網路自動補上。
- Google 授權大約 1 小時過期（瀏覽器 token 模式不保存長期權杖），狀態會顯示「需要重新連線」，按一下「重新連線」即可，期間的修改都保留。
- 兩台電腦改到「同一筆」資料時，不會自動蓋掉：狀態顯示「⚠ 同步衝突」，在設定視窗選「用這台電腦的」或「用雲端的」。
- 作業紀錄是逐筆新增的事件，兩台同時登記同一格時，會在作業畫面標示「⚠ 衝突」讓你選。
- 試算表 A–G 欄是同步用的，請不要手動修改；H 欄之後是給你閱讀、篩選用的。刪除只會標記 `deleted=1`，原資料仍保留在那一列。

## 五、隱私與停用
- 試算表建立在你的雲端硬碟，預設不分享給任何人。請不要用「知道連結的人都能檢視」分享。
- App 只在記憶體保存 Google access token，不寫入 localStorage / IndexedDB，也不會出現在試算表裡。
- 停用：設定視窗按「中斷同步」。本機與試算表的資料都保留；不需要時可自行到雲端硬碟刪除該試算表。

## 六、從舊版 Firebase 搬資料
- v6 不會讀取、修改或刪除舊的 Firebase/Firestore 資料。
- 需要舊雲端資料時：用 v5.1 版本（GitHub `main` 舊版本，commit `44879bb`）開啟 → 「匯出備份」→ 在 v6「載入備份」。導入前 App 會先自動下載目前資料的備份。
- 舊 Firebase 專案要不要停用或刪除，由你自行決定；本專案不會替你操作。

## 七、限制（請知悉）
- Google 試算表不是交易型資料庫：設計為「一位老師、多台裝置」使用。若多位老師同時大量編輯，仍可能需要人工處理衝突；不保證完全強一致。
- Google Sheets API 每位使用者每分鐘讀取約 60 次；App 每次同步約 3–15 次請求，並在 429/5xx 時自動退避重試（5 秒、15 秒、45 秒…最多 5 分鐘）。
- 單一試算表上限約 1000 萬個儲存格；一個 28 人班級一學年的紀錄遠低於此上限。

## 疑難排解
| 現象 | 原因與處理 |
|---|---|
| 「OAuth Client ID 格式不正確」 | 貼到的是密鑰或網址；請貼「用戶端 ID」。 |
| Google 視窗顯示 `origin_mismatch` | 第一節第 4 步的「已授權的 JavaScript 來源」沒有包含目前網址的來源。 |
| 「已拒絕授權」或「沒有勾選檔案存取權限」 | 在 Google 視窗要勾選允許存取檔案；或你的帳號不在「測試使用者」。 |
| 「找不到試算表」 | 試算表被刪除，或是用不同 Google 帳號建立的；請重新建立或改用正確帳號。 |
| 一直顯示「N 筆待同步」 | 檢查網路與授權（重新連線）；資料不會遺失。 |
