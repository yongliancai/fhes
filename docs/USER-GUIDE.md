# 班級經營動力站 v6 使用說明（教師版）

v6 保留 v5.1 的全部功能（加分、愛心提醒與消除、兌換、累計獲得、秩序記錄模式、待確認／駁回／撤銷、時段、每日結算、備份與 CSV），並新增：**作業**、**圖鑑（六大收藏世界）**、**Google 試算表雲端同步**。

> 開啟方式：請用網址開啟（GitHub Pages 正式網址，或在電腦上執行 `npm run serve` 後開 `http://127.0.0.1:8765/`）。v6 由多個檔案組成，**直接雙擊 index.html 會無法執行**。

## 登入（v6.1 起必須）
- 開啟後先看到登入畫面，按「使用 Google 帳號登入」。驗證通過才會進入；在那之前，畫面上不會出現任何班級或學生資料。
- 右上角的帳號按鈕（顯示你的 Email）有這些功能：
  - **登出**：放學或離開座位時使用。
  - **切換帳號**：換另一位老師登入。前一位老師的畫面與資料會全部清掉。
  - **☁️ 雲端重新授權**：重新連接 Google 試算表。
  - **共用電腦：登出並移除這台電腦上此帳號的資料**：會先下載備份，再刪除這台電腦上你這個帳號的班級資料。Google 試算表與其他電腦都不受影響。
- **每個 Google 帳號的資料彼此分開**：同一台電腦上，A 老師登入看不到 B 老師的班級。
- **重新整理頁面**後要再登入一次；同一次登入最長 12 小時，超過會自動鎖定。在一個分頁登出，同帳號的其他分頁也會一起鎖定。
- **網路**：登入需要網路。登入後短暫斷線仍可繼續使用，資料先存在這台電腦，恢復網路後自動同步。
- **安全提醒**：這台電腦上的資料沒有加密。共用電腦請一定要登出；最好每位老師使用自己的電腦帳號，或不同的瀏覽器設定檔。

### 舊資料（登入功能上線前存在這台電腦的班級）
- 第一次登入後，如果這台電腦有舊資料，總覽上方會出現黃色提示。**系統不會自動把舊資料給任何帳號。**
- 按「預覽並選擇是否匯入」可以看到舊班級的名稱與筆數。勾選屬於你的班級，再按「下載備份並匯入勾選的班級」：
  - 系統會先下載一份舊資料備份，再把勾選的班級**複製**到你的帳號。
  - 舊資料仍留在這台電腦，其他老師登入時也可以匯入他自己的班級。
  - 你的帳號裡已經有的同一個班級不會被覆蓋。
- 匯入錯了可以按「查看／復原」→「復原這次匯入」（會先下載備份）。
- 如果那不是你的資料，按「這不是我的資料」，你的帳號就不會再看到提示。
- 所有老師都匯入完成後，可以用「從這台電腦移除舊資料」清掉。會先下載備份，並確認兩次。

## 升級前
1. 在舊版（v5.1）按「匯出備份」保存一份 JSON。
2. 第一次開 v6.1 並登入後，舊資料**不會自動升級或歸屬**，而是用上面的「舊資料」流程，由你選擇匯入（原始資料保留不動，已用合成資料實測）。

## 作業（「作業」分頁）
- **預設是投影模式**：只顯示匿名統計（已交／應交、繳交率、已登記率、訂正完成率），不會出現任何學生姓名。可以安心投影。
- 按「🔒 教師檢視」才顯示姓名與未交名單；離開作業分頁會自動回到投影模式。
- **新增作業**：選類別（國隨、國習、甲本、乙本、數課、數講、數練、數重、數習、成語、考卷）、填範圍與期限。「📋 複製前一天」可一次複製前一天的作業。
- **登記**：點格子選「未登記／未交／已交／免交」。勾選多位同學可批次登記；欄位上方「其餘未登記→未交」可把剩下的人一次設成未交。
  - 未登記 ≠ 未交：沒點過的同學不會出現在未交名單。
  - 已交 ≠ 已訂正：已交之後可再標「待訂正／已訂正／不需訂正」。
  - 過了期限才交會自動標「補交」並記下日期。
- **復原上一批**：今天最近一次批次登記可以復原；之後被改過的格子會保留不動。原紀錄留在歷程中。
- 下方有「待補交」「待訂正」「尚未登記」清單，可直接按「補交了」「已訂正」。
- 點學生姓名看個人作業歷程；「📊 統計」看近 7／30／90 天（依類別為匿名統計，個人統計僅教師檢視）並可匯出 CSV。
- 「⚙️ 作業設定」：新增、改名、停用類別（預設類別與用過的類別只能停用，歷史保留）。正向獎勵預設關閉；開啟後，作業全班交齊時可以按按鈕頒發全班 XP（不會因個別同學未交而扣任何東西）。

## 圖鑑（「圖鑑」分頁）
- 收藏屬於**小隊**或**全班**，不屬於個人。上方切換第 1～N 小隊或全班。
- **XP 怎麼來**（自動，從 v6 開始的紀錄）：
  - 個人加分 +1 → 該生當時所屬小隊 XP +1、全班 XP +1。
  - 小隊加分 +1 → 該小隊 XP +1（只算一次，不乘人數）、全班 XP +1。
  - 扣分、愛心、兌換都**不會**減少 XP；按錯而「復原／撤銷」的加分不計 XP。
  - 也可在「⚙️ 圖鑑設定」手動頒發全班或小隊 XP（需填原因）。
- **探索能量**＝本期 XP − 已用來解鎖的 XP。普通 10、稀有 20、史詩 35、傳說 60（可在設定調整；所有世界相同，主題家園沒有加成）。
- 預設「逐步揭露」：同一個世界要先收齊普通，才能解鎖稀有，依此類推；可改成「自由選擇」。
- **收藏永遠不會被收回**：扣分、兌換、換組、開始新的獎勵期間都不影響。只有老師按「撤銷誤發」（需填原因）才會撤銷，而且紀錄保留。
- 夥伴會隨小隊之後累積的 XP 成長（發現→初成長→成熟→完成紀錄；機械為發現→組裝→升級→完工）。點擊夥伴可互動，不消耗任何分數。
- **全班 XP 里程碑**會在所有棲地出現班級紀念物（星光小徑、彩虹橋、大樹屋…）。
- **特殊收藏**：可新增節慶、紀念版等特殊夥伴，最多 2 個標籤；不占基本 12 格。預設標籤可停用不可刪除；自訂標籤刪除前會列出影響並確認兩次，收藏本身不會被刪。
- 右上角 🐢 可以「減少動態效果」（也會依照電腦的系統設定自動減少）。
- 圖案目前是**原創佔位插畫**（程式繪製），正式美術完成後會替換；陸地以外的角色名單是專家建議，可再調整。

## 雲端同步（選用）
請看 [GOOGLE-SHEETS-SETUP.md](GOOGLE-SHEETS-SETUP.md)。重點：
- 狀態顯示在總覽與班級畫面標題列；「需要重新連線」時按一下重新授權即可，資料不會遺失。
- 離線照常使用，恢復網路自動同步。
- 兩台電腦改到同一筆時會顯示「同步衝突」，由你選擇保留哪一個。

## 備份
- 「匯出備份」產生 v6 JSON（含作業、XP、圖鑑）；v4、v5、v5.1 的備份都可以載入。
- 載入備份前會自動先下載一份目前資料的備份。
