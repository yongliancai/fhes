# 圖鑑美術規範（v7 草案）

狀態：**草案，等待試作樣本確認**（2026-11-25）。

## 決策摘要

| 項目 | 決定 |
|---|---|
| 製作方式 | AI 生圖（Google Antigravity 自動批次執行），提示詞由 `scripts/art-prompts.mjs` 統一產生 |
| 風格 | 收藏公仔風：設計師軟膠公仔（vinyl toy）的 3D 渲染質感 |
| 對象 | 國小高年級（11–12 歲）：帥氣、有自信，不走幼兒風 |
| 展示 | 2.5D 立體園區：分層景深、角色自主行為、可放大與互動（另行設計） |

## 角色規範

- **比例**：半 Q 版，頭約佔身高 1/3。
- **剪影優先**：縮小到 64px 也能認出物種（長頸鹿的脖子、穿山甲的鱗甲、雲豹的花紋）。
- **材質與光線**：霧面軟膠、左上方棚拍柔光、輕微邊緣光與環境光遮蔽。
- **視角**：三分之四側面，**一律面向左**；園區程式以左右翻轉產生往右走的方向。
- **構圖**：正方形，角色置中，約佔畫面 80%，全身完整。
- **背景**：單一純色去背色（洋紅 `#FF00FF` 或純綠 `#00FF00`，依角色主色自動選差異最大者），後製自動去背。
- **原創性**：提示詞不得出現既有作品、公司或角色名稱；結果不得像任何既有角色。

## 世界材質

| 世界 | 材質重點 |
|---|---|
| 陸地 | 暖色自然色，毛髮以雕刻紋路表現 |
| 海洋 | 微濕潤光澤，水藍反光 |
| 天空 | 層疊雕刻羽毛，輕盈粉彩點綴 |
| 科技 | 原創機器人，亮面烤漆、面板接縫、青色燈條 |
| 史前 | 土色系，石紋與化石質感 |
| 奇幻 | 原創生物，內部微光，珠光色澤 |

## 稀有度

| 稀有度 | 視覺 |
|---|---|
| 普通 | 純霧面，平穩站姿，無配件 |
| 稀有 | 一件天藍色小配件（圍巾或徽章） |
| 史詩 | 動態姿勢（紫色光點由程式繪製） |
| 傳說 | 英雄姿勢，金色鑲邊（金色光暈由程式繪製） |

光暈、光點等特效不畫進圖片：去背較乾淨，而且園區裡可以做成動畫。稀有度的顏色、圖示與文字標籤仍保留在介面上（不能只靠美術辨識）。

## 成長階段

| 階段 | 動物路線 | 科技路線 | 呈現方式 |
|---|---|---|---|
| 0 | 發現 | 發現 | 幼年／原型圖 |
| 1 | 初成長 | 組裝 | 幼年／原型圖＋程式特效（小徽章） |
| 2 | 成熟 | 升級 | 成年／完工圖 |
| 3 | 完成紀錄 | 完工 | 成年／完工圖＋程式特效（腳下光圈、光環） |

每隻只生 2 張圖（共 144 張），第 1、3 階段的差異由程式加上，以維持風格一致。

## 2.5D 立體園區（已實作，2026-11-25）

- 程式：`src/ui/zoo.js`（畫面、鏡頭、互動）、`src/core/zoo-sim.js`（行為模擬，純函式，有單元測試）、`src/art/zoo-props.js`（道具）、`src/ui/zoo.css`。
- 景深：角色有深度 z，越遠越小、越暗、越後面；道具也有深度，角色會走到樹叢後面。滑鼠移動時背景有輕微視差。
- 移動方式：陸地走路、海洋游泳（螃蟹與海星在海底爬）、鳥類與無人機飛行。體型分大中小。
- 自主行為：閒晃、休息、睡覺 💤、吃東西、玩耍、站崗 👀（狐獴、巡邏機器狗）、兩隻靠近時打招呼 💬❤️。物種習性不同：樹懶與貓頭鷹愛睡、蜂鳥停不下來、水豚很悠哉。
- 互動：點角色 → 鏡頭拉近並跟隨，面板可「餵食」「拍拍」「詳情」；＋／－ 放大縮小、拖曳平移、雙擊放大、⟲ 回到全景、⛶ 全螢幕（投影用）。Esc 取消選取。
- 特效（程式繪製）：史詩紫色光點、傳說金色光暈、完成階段腳底金色光圈（飛行／游泳改為金色外光）。
- 減少動態：角色停在原地，保留選取、縮放與互動。
- 圖片：有核准的 AI 圖就用圖片，其餘自動退回原本的佔位 SVG，所以可以邊生成邊上架。
- 已知問題：史前世界的滄龍沒有水域，目前在空中游動；成年／幼年 AI 圖與 SVG 佔位圖混在一起時風格不一致（量產完成後自然消失）。

## 園區場景設計（v7.1，2026-11-25）

問題：原本的 SVG 場景是平塗色塊，和 3D 公仔角色放在一起顯得陽春、風格不一致。

做法：把場景拆成四層，每層各司其職：

| 層 | 內容 | 來源 |
|---|---|---|
| 1 背景板 | 每個世界一張寬幅「微縮場景」：遠景、天空、光線，下方留空地 | AI 生成（`bg-<世界>`），沒有時退回 SVG |
| 2 遠景動態 | 飄動的雲、海中光束與遠方魚群、極光與星星、遠方飛行剪影 | 程式（`src/art/ambient.js`） |
| 3 舞台 | 角色＋道具，依深度排序；角色可以走到樹叢、珊瑚後面 | 角色與道具 AI 圖，沒有時退回 SVG |
| 4 近景動態 | 蝴蝶、落葉、泡泡、螢火蟲、塵埃、四周暗角 | 程式 |

- 背景板提示詞規定了空地的位置（例如陸地下方 35%），和程式的地平線設定一致，角色才會「站在」地面上。
- 背景板顏色比角色柔和，讓角色突出。
- 全班里程碑（星光小徑、彩虹橋、大樹屋、噴泉廣場、觀星塔、班級紀念碑）改成 AI 道具擺進每個世界，取代原本每個世界都一樣的彩虹。道具圖還沒做好時，先顯示告示牌（圖示＋名稱）。
- 每個世界 4–7 個道具，位置寫在 `src/art/zoo-props.js`。
- 減少動態：環境動態全部停止，會移動的小物件隱藏。

## 流程

1. **試作**：`land-01` 貓咪（普通）、`ocean-07` 海龜（稀有）、`tech-10` 智慧探勘機（史詩）、`fantasy-12` 遠古守護龍（傳說）。使用者檢查後選出風格基準圖。
2. **量產**：Antigravity 依 `art/ANTIGRAVITY-TASK.md` 生成其餘角色，存到 `art/raw/`（不提交，已列入 `.gitignore`）。
3. **核准與後製**：把通過的圖加進 `art/approved.json`，執行 `python scripts/art-process.py`（需要 Pillow）：自動去背、裁切、輸出 512px WebP 到 `assets/creatures/`，並更新 `src/data/art-manifest.js`。
4. **授權紀錄**：依 `art/raw/generation-log.csv` 更新 `docs/ASSET-LICENSES.md`（工具、模型、日期、提示詞來源）。使用前需確認所用 Google 服務的生成內容使用條款。
